# Country: Canada (CA)

- **Priority rank:** 1
- **Target role:** Full-stack / backend JavaScript developer (Senior Backend Engineer band)
- **Migration route via job offer:** Global Talent Stream (GTS) — Category B (digital occupations) → work permit; Express Entry (FSW / CEC / category-based STEM) for PR
- **Language requirement:** English (French only for Montreal roles and for French-language EE category draws)
- **Sponsorship common?:** Yes — GTS is the employer-friendly tech path; 4/10 sampled offers with full immigration support. Note: title must be on the Global Talent Occupations List (Category B) to use GTS.
- **Known blockers:** High cost of living in Toronto/Vancouver; GTS salary floor (provincial median "high-wage" threshold) for Category B roles; EE job-offer CRS points removed (Mar 2025) so employer sponsorship no longer boosts PR score; category-based draws favour STEM/French/healthcare and general (CEC) cutoffs are high (507–518).
- **Primary job boards / sources:**
  - LinkedIn, Indeed.ca, Glassdoor, Workopolis
  - Relocate.me (Global Skills Hub), YCombinator Jobs, Wellfound
- **Notes (updated Aug 2026):**
  - **New: AI worker stream under GTS announced Jun 4, 2026** — proposed expedited work-permit stream for AI professionals (20-day end-to-end), part of the Carney govt "AI for All" strategy (targets 250k AI jobs by 2034). No launch date or qualification details yet. Watch for whether it widens GTS beyond AI into broader tech.
  - **GTS still the fastest employer route:** ~10-day LMIA + ~10-day work-permit processing for Category A/B, vs 2–6 months for a standard TFWP permit. LMIA processing times overall are rising (Mar 2026).
  - **Express Entry now (Aug 2026):** 108,123 ITAs issued YTD. 10 category-based selection categories — STEM included; category draws run at far lower cutoffs (healthcare/social ~462–476 CRS) vs Canadian Experience Class (CEC) general draws (507–518). Strong English + in-demand category = most realistic PR lever.
  - **Job-offer CRS points were removed Mar 25, 2025** (anti-fraud re: purchased LMIA). IRCC dept plan (Mar 13, 2026) proposes reintroducing points for *high-wage* job offers + Canadian work experience + regulated occupations — announced but NOT yet implemented; no timeline. Re-check periodically.
  - **Salary:** Senior backend engineer Canada average ≈ C$146K/yr gross (talent.ca, 2026). Master-profile opening ask C$105–120K (Toronto/Vancouver senior band) sits safely above both that average's lower range and the GTS high-wage floor. C$90K minimum is a fair walk-away floor.
  - **Iranian nationals:** no blanket work-visa restriction observed as of Aug 2026 — re-verify before applying given policy volatility.
  - **Unique advantage:** PR possible via Express Entry without an employer if CRS qualifies independently (esp. via a STEM category draw); this reduces dependence on employer sponsorship for long-term status.
