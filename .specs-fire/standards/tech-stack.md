# Tech Stack

## Overview

jobHunter is a personal job-search workspace: Markdown workflow docs (phases 0–3) plus a local Bun tool (`tools/job-collector`) that collects offers, parses them with an LLM, stores records in SQLite, and generates tailored CV markdown into the repo.

## Core Technologies

### Language

**Primary**: JavaScript (ESM)
**Version**: ES2022+

### Framework

**Framework**: Express (API) + React (UI)
**Version**: Express 5 / React 18
**Rationale**: Lightweight local tool — Express for REST, React SPA for operator UI; no NestJS/Next for the collector itself (those are target-role skills, not this app’s stack).

### Runtime

**Runtime**: Bun
**Version**: 1.x
