# Project Constitution

> Universal policies that apply to ALL code in this project.
> This file is always inherited from root — modules cannot override it.

## Git Workflow

- **Commit Style**: Conventional commits (feat:, fix:, chore:, docs:, refactor:, test:)
- **Branch Strategy**: Feature branches merged via pull request
- **Main Branch**: master is always deployable

## Code Review

- All changes require pull request review
- At least one approval required before merge
- No self-merging to main/master
- Security-sensitive changes require additional review

## CI/CD

- All PRs must pass CI checks before merge
- Automated tests run on every push
- Main branch deployments are automated

## Security Policies

- **No secrets in code** — use environment variables or secret management
- Dependencies must be from trusted sources
- Security vulnerabilities addressed within SLA
- No credentials, API keys, or tokens in source control
- Never commit `.env`, API keys, or Anthropic/Ollama credentials
- Job-collector scrapers must respect site terms; prefer manual/authenticated flows where required

## Documentation

- Public APIs must be documented
- Breaking changes require migration notes
- README kept up to date with setup instructions
- Workflow decisions live in `docs/principles.md` — update when rules change

## Workflow Integrity (jobHunter-specific)

- Master profile is the single source of truth for experience — never invent beyond it in CVs
- AI drafts require 100% human review before send
- Phase 2 (applications) and Phase 3 (upskilling) run in parallel
