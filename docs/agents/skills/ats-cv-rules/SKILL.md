# ATS CV Rules

- Keep the CV single-column and use the declared section order: Professional
  Summary, Skills, Work Experience, Selected Projects, Education, Languages.
- Place a target keyword in a relevant experience or project bullet when the
  master profile provides direct evidence; do not add unsupported keywords only
  to improve matching.
- Use the job posting's terminology only when it accurately describes the
  candidate's verified work. Do not substitute adjacent technologies.
- Prefer standard Markdown headings and plain text over tables, icons, columns,
  ratings, or decorative formatting.
